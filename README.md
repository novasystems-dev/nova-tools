## 🛠️ Included Tools

1. **`nova-fmt`**: Deterministic code formatter enforcing official Nova indentation and style rules.
2. **`nova-lint`**: Static analysis engine flagging unsafe pointer dereferences, dead code, and unproven invariants.
3. **`nova-doc`**: Automated Markdown API documentation generator extracting doc-comments from Nova source code.
4. **`nova-repl`**: Real-time read-eval-print loop with interactive Pratt expression evaluation.
